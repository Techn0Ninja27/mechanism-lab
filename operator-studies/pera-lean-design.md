# Lean formalization design for the PERA counterexample

Date: 2026-11-18.

Historical planning note, superseded by the [completed Lean project](pera-lean/README.md).
The implementation proves the stronger positive-distance and infimum bounds.

The full spectral-norm lower bound is mathematically elementary but is a poor
first Lean target: it requires finite-dimensional operator norms, row spaces,
rank, a kernel vector, and a quantitative angle estimate. The first theorem to
formalize should instead certify the implication needed to refute Appendix A.3:

```text
if a PERA update were equal to the rank-two projector P,
then the projector's row space would contain a nonzero coordinatewise
nonnegative vector; but P's row space is the zero-sum plane, which contains no
such vector.
```

This establishes `P ∉ S_PERA`. Since the paper's displayed bound for `r = 1`
and `P` has right side `sigma 3 P = 0`, non-membership rules out an exact
representation. By itself it would not rule out arbitrarily close approximation
or a zero infimum. The completed project therefore proves the stronger
`1 / sqrt 3` distance bound and the positive infimum directly.

## Recommended Lean decomposition

Use `ι := Fin 3` and `Matrix (Fin 3) (Fin 3) ℝ`. Define

```lean
def sq (a : Fin 3 → ℝ) := fun i => a i * a i
def pera (a b : Fin 3 → ℝ) (h : ℝ) : Matrix (Fin 3) (Fin 3) ℝ :=
  fun i j => b i * a j + h * sq b i * sq a j
def P : Matrix (Fin 3) (Fin 3) ℝ :=
  fun i j => if i = j then (2 : ℝ) / 3 else -(1 : ℝ) / 3
```

Avoid matrix inversion, singular values and operator norms in the initial
file. Prove the following small lemmas first, all by `fin_cases` and `ring` or
`norm_num`:

1. `P 0 0 = 2/3`, `P 0 1 = -1/3`, and the corresponding entries needed below.
2. `P i j = P j i`.
3. `∑ j, P i j = 0` and `∑ i, P i j = 0`.
4. `P` has two independent rows, e.g. the first two rows; this can be done by
   applying a putative linear relation to the explicit coordinates rather than
   invoking `Matrix.rank`.
5. If `x : Fin 3 → ℝ` is coordinatewise nonnegative and `∑ i, x i = 0`, then
   `x = 0`. This is the key positivity lemma and is usually easiest by
   `fin_cases` plus `positivity`/`nlinarith`.

The robust row-space route is:

```text
assume pera a b h = P
show the row vectors a and sq a span the row space of P
  (if they are dependent, pera has rank ≤ 1, contradicting the independent
   first two rows of P)
therefore sq a is in the row space of P
P's row space is the zero-sum plane
sq a is coordinatewise nonnegative and is nonzero
contradiction with the positivity lemma.
```

In Lean, do not start by proving an abstract `finrank` equality. Represent a
row-space membership witness explicitly. The rows of `pera` have the form
`b i • a + (h * b i^2) • sq a`, so each row belongs to
`Submodule.span ℝ {a, sq a}`. If `a` and `sq a` are dependent, every row is a
multiple of `a`, hence the first two rows of `P` are dependent. The remaining
case gives an explicit two-vector basis. For the final contradiction, use the
fact that every row of `P` has coordinate sum zero and transfer the same fact
to every linear combination.

Useful APIs to try in a Mathlib project:

```lean
Submodule.span ℝ ({a, sq a} : Set (Fin 3 → ℝ))
Submodule.mem_span_pair
Fintype.sum_fin_eq_sum_range
Fin.sum_univ_succ
Matrix.mulVec
Matrix.row
Matrix.ext
```

If the row-space proof becomes too expensive, formalize the exact finite
coordinate certificate generated by it: expose coefficients `α i β i` such
that each row of `P` equals `α i • a + β i • sq a`, derive the zero-sum identity
for `sq a`, and then use `nlinarith` on the nine entries. This keeps the theorem
about the actual PERA family while avoiding a general rank API.

## Quantitative theorem later

After membership is proved, define the normalized all-ones vector `n` and a
unit vector in the right kernel of `M`. The quantitative proof needs:

```text
||P v||² = 1 - (n · v)²,
u = sq a / ||sq a||,  u ≥ 0, ||u|| = 1,
n · u ≥ 1 / sqrt 3,
v ⟂ u  ⇒  |n · v| ≤ sqrt(2/3).
```

This should use `EuclideanSpace ℝ (Fin 3)` and `@inner ℝ _ _`, not raw matrix
operator norms at first. A useful intermediate theorem is the finite-vector
inequality `‖P v‖² ≥ 1/3` for every unit `v` orthogonal to a nonzero
coordinatewise nonnegative vector. Only then connect it to
`‖P - pera a b h‖`; keep this as a separate file so the exact non-membership
refutation remains small and stable.

## What Lean must not claim

The formal file should state the theorem as a correction to the paper's
approximation argument. It should not claim that PERA is useless, that the
benchmark is invalid, or that the counterexample is novel. It should also
record that the source theorem's set-containment step has the inequality in the
wrong direction:

```text
S_PERA ⊆ {M | rank M ≤ K}
⇒ inf over rank-K matrices ≤ inf over S_PERA,
not the reverse.
```

The executable target-matrix checks already in `operator-studies/pera-rank-counterexample`
are not a substitute for the Lean proof: they should remain as a separate
numeric sanity check.
